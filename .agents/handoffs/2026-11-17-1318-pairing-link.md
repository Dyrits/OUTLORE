## Goal

## Decisions

- The text code stays, shown on its own block beside the QR and links (owner, 2026-11-17, quest journal entry 2). Recorded in the specification (CHG-0434).
- The QR encodes the web link `<web app address>/#<code>`; the app link is `outlore://pair#<code>`; the code stays in the fragment so no server or log sees it.
- `uqr` over `qrcode-generator`: MIT, no dependency, 27 KB, returns the matrix for one react-native-svg drawing. Not added to `third-party-notices.txt`, which lists adapted code only.
- A browser with no host pairs without a question; a browser with a host, and the desktop app, show the relay and wait for Pair. The desktop confirmation names the relay, not the host (the code does not carry the host name).
- A development run or a check does not register `outlore://` (it would take the links from the installed app); `OUTLORE_HANDLE_LINKS=1` opts a development run in. Of several links that arrive before the window is ready, the latest is kept.
- Web links use the shared relay's web app even when the host uses its own relay, as the Remote access view does.
- Changelog entries CHG-0434 and CHG-0435 (`documentation/changelog/0.1.6-Prototype.md`); another branch may take the same numbers: renumber on merge.
