## Decisions

- **`werift` (`^0.28.0`, MIT) for Node/Electron** (ADR 0026): pure TypeScript, zero native C++ addons, lazy-loaded on first direct channel, `iceUseDefaultStunServer: false`. Avoids native prebuild complexity for Electron and standalone hosts (ADR 0018).
- **Noise NK inside the WebRTC data channel** (ADR 0026): fresh Noise NK handshake bound to `outlore-direct/1 <room> <attempt>`, so DTLS is not the end-to-end layer.
- **Default STUN server `stun:stun.cloudflare.com:3478`** (ADR 0026, `packages/channel/src/directSettings.ts`): same provider as the shared relay so no second third party sees the owner's IP; overridable with `OUTLORE_STUN_SERVERS`. Marked to confirm with the owner.
- **No TURN server** (ADR 0026): the relay Worker remains the automatic fallback when direct hole punching fails or drops.
- **Mobile app stays on the relay** (ADR 0026, `apps/app/src/foundation/browser/page.ts`): Hermes lacks `RTCPeerConnection`; adding `react-native-webrtc` is deferred for an explicit owner decision.
- **Max 16 concurrent direct peers per host** (`maxDirectPeers = 16` in `packages/service/src/remote/hostSession.ts`), returning `DirectRefusal("busy")` beyond that.
