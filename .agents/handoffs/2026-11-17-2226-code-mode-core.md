## Decisions

- Build Code Mode's core ahead of the connectors, against a fake gateway (owner, 2026-11-17; CHG-0441 in `documentation/changelog/0.1.7-Prototype.md`).
- Executor: QuickJS compiled to WebAssembly inside the host service, a fresh runtime per run (owner, 2026-11-17; ADR 0023). Not `@cloudflare/codemode` as a dependency, not a Cloudflare Worker, not a native isolate.
- With Code Mode on, a direct connector call is refused; the code tool is unknown while it is off (`codeMode.ts`).
- A call that ends before `Effect.runFork` returns is settled in a microtask, after QuickJS leaves the host function (`codeRunner.ts`); settling inside it freed the promise handle before its return.
