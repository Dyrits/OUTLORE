## CHG-0661 · 2026-11-23 · Force the host update over running turns

Type: Code
Event: Agreement and delivery
Scope: app-updates, Updating a host from a paired device

Summary: While a paired device shows "Waiting for N running turns to finish", it offers **Force update**. After a confirmation naming the turns that stop, it sends the new `ForceUpdateHost` request and the host installs without waiting; the install quits the host, which ends the turns as the desktop's Restart and update does. A plain **Update host** still waits. A host from before the request fails it, shown as a too-old text.
Reason: The owner met the waiting banner on a phone with no way out but stopping the turn by hand on the host, and asked to be able to force the update (2026-11-23).
Validation: The service, device and app tests for the force pass (host update 12, device update 5, app host update 16); typecheck and Biome results are in the verification note of the batch. A real phone and a packaged macOS update were not tried.
