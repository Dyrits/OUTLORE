# 0.2.8-Pre-Alpha

## CHG-0738 · 2026-11-25 · Copy buttons on replies and code blocks

Type: Code
Event: Agreement
Scope: Conversation panes

Summary: An agent's reply now has a Copy button at the right of the line under it, which copies the reply's Markdown text, and every code block in a reply has a Copy button in its top right corner, which copies only that block's code.
Code blocks and inline code are drawn on a veil of the text color with a border, so they stand apart from the message in every theme, where the surface color alone was close to the card's own.
Each button shows a check mark for about a second and a half after copying; a draft that is still being written has none.
Reason: The owner asked for a way to copy a response, and a code block, directly, for example to paste release notes (2026-11-25).
Validation: Biome and the app typecheck pass; the desktop window check and owner acceptance are pending.

## CHG-0739 · 2026-11-25 · Quest suggestion card as a destination list

Type: Code
Event: Agreement
Scope: Quest suggestions

Summary: Chronicler's quest proposal and a thread's off-topic suggestion are now one list of destinations (option B of `documentation/art-direction/2026-11-25-suggestion-card.html`) in a plain bordered card, replacing the red box.
Quests that may already cover the request come first as "Continue" rows; the new quest is one row that names its realm and Companion; an off-topic message adds a "Keep here as an aside" row.
With no matching quest the card is just the new-quest row, and the Realm and Companion chips and pickers stay folded behind its "Change" link.
Matching skips a Fulfilled or Archived quest that ended more than `endedQuestMatchDays` ago, a Settings number under Quest upkeep that defaults to 14.
Reason: The owner found the card awful and asked for only the first options up front, with existing quests offered only when one really matches, and for old finished or archived quests to be ignored (2026-11-25).
Validation: Biome, the app and service typechecks, and the off-topic tests pass, including a new test for the 14-day rule; the desktop window check and owner acceptance are pending.
