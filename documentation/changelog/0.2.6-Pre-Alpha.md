# 0.2.6-Pre-Alpha

## CHG-0711 · 2026-11-24 · A new custom preset is made in the Companions tab

Type: Code
Event: Delivery
Scope: Workshop Companions

Summary: Add preset in the Workshop asks only for a name, saves the preset on the default Companion, and opens it in the Companions tab, where its Companion and backups are chosen and saved at once, as a built-in preset's are.
The full Harness, Companion, and backup pickers no longer appear below the list, and with them the clipped effort labels in their backup rows.
Reason: The owner found that a custom preset worked like a built-in one once saved (CHG-0684) but was created in a different form below the list instead of in the Companions tab (2026-11-24).
References: [Companion presets](../capabilities/companion-presets/specifications.md).
Validation: Workspace typecheck and the 56 settings and editor tests passed. The running Workshop still needs a visual check.

## CHG-0712 · 2026-11-25 · Add preset opens a draft in the Companions tab, and Overwrite returns a changed Companion to its preset

Type: Code
Event: Delivery
Scope: Workshop Companions, Companions tab

Summary: Add preset in the Workshop no longer asks for a name first. It opens the Companions tab on an unsaved draft that starts as a copy of the Companion the tab shows, and Save as new preset asks for the name at the end, then shows the new preset. Discard, closing the tab, or choosing another Companion drops the draft.
In the Companions tab of a quest, an errand, or a realm conversation, Overwrite appears once the Companion or its backups differ from the preset last chosen there and, after one confirmation, replaces that preset's whole stack. The Workshop has no Overwrite, since a saved preset there already saves each change at once.
Reason: The owner found the name form ahead of the tab backwards, and asked that Overwrite belong to changing a preset in a quest, realm, or errand (2026-11-25). Replaces the name-first flow of CHG-0711.
References: [Companion presets](../capabilities/companion-presets/specifications.md).
Validation: Workspace typecheck, Biome, and the 821 app tests passed. The running app still needs a visual check of the draft, the reveal, and Overwrite.

## CHG-0713 · 2026-11-25 · The Workshop's draft preset reaches the Companions tab

Type: Code
Event: Delivery
Scope: Workshop Companions

Summary: Add preset (CHG-0712) did nothing visible: the draft lived in the Workshop page's own provider, but the shell draws the Companions tab outside that provider and draws it again only when its key changes, so the tab always saw no draft. The draft now lives in `apps/app/src/settings/workshopDraft.ts`, a small store the tab subscribes to, and the page and the tab both read it there.
Reason: The owner reported that CHG-0712 "doesn't really work" (2026-11-25); the cause was found by reading how the shell draws the tab (`isSamePicker` compares the tab's key, not its props).
References: [Companion presets](../capabilities/companion-presets/specifications.md).
Validation: Workspace typecheck, Biome, and 822 app tests passed, with a new test for the store. The running app still needs a visual check; the owner has not yet said what exactly failed.
