# Changelog: 0.1.8-Prototype

## CHG-0445 · 2026-11-18 · The Android app no longer crashes once a pairing connects

Type: Code
Event: Delivery
Scope: App (Guild Hall hub), release

Summary: The owner reported that the Android app (0.1.7-Prototype, installed from the debug-signed build) crashed after a pairing was attempted. `adb logcat -b crash` held two crashes, both `TypeError: undefined is not a function` thrown in `hubOf` and called from `GuildHallHub`, which renders as soon as a pairing connects. Cause: `hubOf` sorted the quests with `Array.prototype.toSorted`, and Hermes, the phone app's engine (React Native 0.88.1), does not have it. The engine's own Array table in `libhermesvm.so` of the installed APK lists `toReversed`, `toSpliced`, `with`, `findLast` and `flatMap`, but not `toSorted`. TypeScript's library does know it, so the typecheck passed. `hubOf` now sorts a copy (`[...missions].sort(...)`). A guard test fails when the code the phone bundles (the app, `contracts`, `controller`) calls `.toSorted(`. This hotfix release carries that fix and nothing else; the version moves to 0.1.8-Prototype.
Reason: A phone that pairs but crashes on the first screen is unusable, and 0.1.7-Prototype is the first release with the Android app.
References: CHG-0298, CHG-0443, `apps/app/src/conversation/guildHall.ts` (`hubOf`), `apps/app/test/conversation/guildHall.test.ts`, `apps/app/test/foundation/hermesBuiltins.test.ts`, `apps/app/test/raw.d.ts`.
Validation: the new test in `guildHall.test.ts` ran `hubOf` without `Array.prototype.toSorted`: it failed with the crash's `TypeError` before the fix and passes after. The guard test failed on a planted `.toSorted(` call and passes on the tree. All 72 app test files (511 tests passed, 8 skipped), the app's typecheck and Biome pass. Not checked: the fixed app on the phone (needs the 0.1.8 APK), the rest of a pairing from the phone (camera, `outlore://` link), and other built-ins newer than Hermes: the client code was searched for `toSorted`, `toReversed`, `toSpliced`, `findLast`, `Object.groupBy`, `Array.fromAsync`, `Promise.withResolvers` and the new Set methods, and only `toSorted` is used (the few `.at(-1)` calls are on arrays, which Hermes has); a built-in outside that list was not looked up.
