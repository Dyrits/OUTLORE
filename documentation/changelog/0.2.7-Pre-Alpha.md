# 0.2.7-Pre-Alpha

## CHG-0721 · 2026-11-25 · The idle host traffic fix is re-checked on the release tip and the refetch cost is measured

Type: Documentation
Event: Delivery
Scope: Host service (`Sessions`), app (`useServiceQuery`, `ServiceClient`); documentation only

Summary: On `a8416f70` the byte loop passes again: a 6,000-character reply in 3-character deltas sends 41 `Draft` frames and 9,653 bytes, and 50 commits send 2 `Changed` frames. The installed 0.2.6 app on the owner's machine holds the relay link flat (7,879 bytes in, 4,263 out over 28 minutes) and has no direct-channel socket without a page; its loopback link to the desktop window still carries about 0.9 MB/s while four agents work. A fixture with 30 quests sized each refetch (`ReadChronicle` 18 KB, `ListConnectors` 7 KB, `ReadAccountBudgets` 5 KB, `ReadSettings` 0.8 KB sent from up to 12 call sites): every call site refetches on every `Changed` frame, so one `Changed` frame can cost about 120 KB with every call site mounted. Recommendation, not built: first share one request between identical queries in `ServiceClient`; give `Changed` a scope only if that is not enough.
Reason: CHG-0719 was delivered with the live measurement and the refetch question open.
