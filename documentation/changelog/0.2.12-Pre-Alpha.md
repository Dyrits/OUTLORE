## CHG-0787 · 2026-11-27 · In-frame Companion follow-ups, opt-in context, and side-chat jump menu

Type: Code
Event: Delivery
Scope: Thread messaging, migration `0083_companion_frames`, `packages/contracts`, `packages/service/src/work`, `apps/app/src/conversation`
Summary: Added `frame_message_id` and `is_context_shared` (default `0`) on `companion_exchanges`, optional `frameMessageId` on `SendMessage`, `ShareCompanionFrame`, and optional `companionFrameId` and `companionFrameContext` (`"None" | "Shared" | "Outdated"`) on `Message`.

Reason: The owner wanted to hold side conversations inside a frame without polluting the main Companion's context unless explicitly shared, and a lightweight way to jump back to side conversations.

## CHG-0788 · 2026-11-27 · A Companion is refused for a usage limit only by a limit that covers its model

Type: Code
Event: Delivery
Scope: Companion refusals, `packages/service/src/work/companionRefusals.ts`, `packages/service/src/harness/antigravityPlanLimits.ts`
Summary: A Companion of Antigravity's Gemini model answered "Cannot answer: its usage limit is reached (resets at Dec 2, 07:05 PM)" while the owner still had Gemini quota, because `usageLimitOf` took the first used-up window of the account whatever model group it belonged to, and the "Others · Weekly" window (Claude and GPT models) was at 100%. A window now refuses a Companion only when it covers the Companion's model: Antigravity's grouped windows ("Gemini · …", "Others · …") cover the models of their group, and any other window covers every model of its harness, as before. `antigravityGroupOf` and `antigravityLimitAppliesTo` in `antigravityPlanLimits.ts` are the one rule that both labels a window and decides who it refuses, so the two cannot drift (a model id starting with "gemini" is Gemini, any other is Others). When several windows that cover the model are used up, the reply now tells the latest reset (it told the first one found), because the Companion can answer only once all of them have reset.
Reason: The owner asked "@Gemini 4 Neon (Medium) Do you have access to Composio?" and was told the limit was reached although Gemini had 60% of its week left.
References: [thread-messaging specifications](../capabilities/thread-messaging/specifications.md) (a model that cannot answer), CHG-0781, CHG-0770 (Antigravity plan limits).
Validation: see the work-in-progress entry; the new tests fail on the starting commit and pass on the end state. Not run: a live Antigravity turn.
