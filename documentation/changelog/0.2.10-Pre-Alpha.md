# 0.2.10-Pre-Alpha

## CHG-0756 · 2026-11-26 · The History tab can show archived quests

Type: Code
Event: Agreement and delivery
Scope: Realm channel, History tab

Summary: The History tab has a "Show archived quests" switch above the list, off by default and kept only while the tab is open.
Switched on, the realm's (or the Borderlands') archived quests join the list under their last-activity headings, each line reading "Archived" before its harness and model and offering no archive button; pressing one opens it as the Archived view does.
`historyQuestsOf` picks the quests of the tab, and `archivedMissions` is the shared query for the Archived view's missions.
Reason: The owner asked that the History tab in the realm allow showing or hiding archived quests (2026-11-26).
The switch is local to the tab rather than an owner setting; a setting would be a small follow-up if wanted.
References: [Mission tracking specification](../capabilities/mission-tracking/specifications.md), CHG-0686.
Validation: `CI=1 bun run test apps/app/test/shell/questTree.test.ts` passed 26 tests (two new for `historyQuestsOf`) and Biome reports no error, and the app typecheck passes. Not checked in a running desktop window.

## CHG-0757 · 2026-11-26 · Ten phone shell directions drawn for the owner to choose from

Type: Documentation
Event: Agreement
Scope: Phone shell, art direction

Summary: A self-contained page of ten live phone mockups (A to J) compares different information architectures for the phone's bottom bar: a Slack-style four tabs (A), a Duet-style bar with the Chronicler in the middle (B), a raised "new quest" button (C), Chronicle / Realms / Quests / More (D), a floating pill that collapses on scroll (E), a "now working" strip above the bar (F), realms as tabs (G), two tabs and one composer with a drawer (H), an inbox segmented by Attention, Running and Done (I), and a thin bar with a sheet that expands (J).
Each shows the Chronicle with its Attention badge, a quest conversation with the composer pinned, and the footer places (Lore, Archive, Reserves, Settings); a comparison table and a recommendation (D first, then B) follow the grid.
No app code changed.
Reason: The owner asked that the phone look more like Claude Duet or the Slack mobile app, with a bottom bar like theirs (2026-11-26), and wanted options before any code changes.
References: [mobile shell page](../art-direction/2026-11-26-mobile-shell.html), [Claude Duet research](../research/claude-duet-2026-11-22.md), CHG-0647 (the phone Chronicle batch).
Validation: The page opened in headless Chrome for Testing in dark and light with no script error and no element past a phone's edge; every phone's bar, a quest, Back, the sheets and drawers, the answer-an-Attention-card count, the floating pill's collapse and the sheet's detents were driven and screenshotted. Not checked on a real phone or in Safari.
