# Changelog: 0.1.4-Prototype

## CHG-0282 · 2026-11-14 · Agree on browser access and a host apart from Electron

Type: Documentation
Event: Agreement
Scope: Architecture, host lifecycle, browser access

Summary: The owner agreed that the shared interface and host must not require Electron, browsers must reach a host without installing anything on their device, and the host may keep running after the desktop app quits. Iskios's code stays TypeScript with Effect and one Expo interface; no Rust migration. Four access requirements record browser access, no additional networking tools, an independent host lifecycle, and feature parity. The owner prefers Bun if it fits; the recorded macOS Bun probe failed at SQLite extension loading, so the runtime decision follows in CHG-0283.
Reason: Reach the same host from any device, without a separate backend per client.
References: [0017](../architecture-decision-record/0017-typescript-and-effect-no-rust.md), [requirements](../requirements.md#access), [backlog](../backlog.md).
Validation: The owner's first-round answers in this thread. Documentation only; no implementation claim.

## CHG-0283 · 2026-11-14 · Agree on host lifecycle, remote terminals, and host-side updates

Type: Documentation
Event: Agreement
Scope: Architecture, terminals, updates, naming

Summary: Node runs the host independently, using the desktop binary as Node in packaged builds. A per-user login service supports Keep running after quitting; a lock and private endpoint/token file serve local clients without changing persisted remote pairings. Optional sleep prevention applies while turns run. Terminals move to the host with OS confinement for paired devices. Updates run through the host and restart Iskios, not the computer. The relay serves release-matched web builds; clients of another release are refused. Desktop, web, and mobile apps share the Expo base. Tauri is excluded. New requirement: Updates keep the host reachable.
Reason: Keep an unattended host usable from a browser without losing its features or requiring another sign-in after updates.
References: [0018](../architecture-decision-record/0018-host-service-runs-on-its-own.md), [0019](../architecture-decision-record/0019-browsers-use-the-relay-served-web-app.md), [0020](../architecture-decision-record/0020-terminals-run-in-the-host.md), [Paseo research](../research/paseo-daemon.md), [glossary](../glossary.md#devices).
Validation: The owner's second-round answers. Sleep prevention being on by default and failed-update rollback are agent recommendations recorded in the design, not separately confirmed product decisions. No implementation or cross-platform verification is claimed. Browser code delivery trust remains open.

## CHG-0284 · 2026-11-14 · Keep Electron for now without Electron-only features

Type: Documentation
Event: Agreement
Scope: Desktop shell, future branding

Summary: Electron stays for now to ship Node and a desktop window, while its features move into the host or gain web equivalents. The inventory is in 0018; a no-shell desktop and Electrobun remain later comparisons. Separately, the owner requested a future app rename to Outlore; Iskios remains a theme with its icon. ## CHG-0285 · 2026-11-15 · Rename the app Outlore, the assistant Chronicler, and make One the default theme

Type: Code
Event: Agreement
Scope: Product naming, themes

Summary: The owner chose the rename recorded as upcoming in CHG-0284 and settled it as follows.
- The app is **Outlore**, renamed in full as in CHG-0143: window, installer and bundle names, update artifacts, user agent, packages (`@outlore/*`), environment variables (`OUTLORE_*`), the desktop bridge (`window.outlore`, `outlore:*` channels), the database file (`outlore.sqlite`), the thread tools' MCP server (`mcp__outlore__…`), the bundle identifier (`app.outlore.desktop`), and the pairing code's prefix (`outlore1-`). The first launch of the installed app moves an `Iskios` data folder and its database into `Outlore`, as earlier renames did.
- **Iskios** stays the name of a theme (with Gild and One), keeping its application icon. The owner supplied a new icon and then asked to leave it unused for now: no icon changed.
- **One** is the default theme, listed first, for a first start or an unknown stored value; a stored choice is kept.
- The assistant (the permanent conversation in the Guild Hall) is renamed **Chronicler**, by the owner's answer; its stored titles follow by migration 0050. The code identifiers that named it (`isIskiosOpen`, `iskiosDock.tsx`, and the like) say Chronicler.
- Renamed too, at the owner's word that a prototype may break between releases: the app scheme `outlore-app` and the browser storage keys (`outlore.theme`, `outlore.colorScheme`, and the rest), so saved theme, look, drafts and comments are lost once; the Noise handshake label `outlore/1`, so devices paired before must be paired again; and the shared relay `outlore-relay` (Worker name, default address `outlore-relay.dyrits.workers.dev`, the default name of an own relay), which has to be deployed before a release or pairing has nothing to reach.
- The first Outlore release, `0.1.4-Prototype`, publishes each macOS installer under both names (the workflow copies only for that tag, so 0.1.5 and later carry Outlore names only), `Outlore-<version>-mac-<arch>.dmg` and `Iskios-<version>-mac-<arch>.dmg` (the same file, both listed in `SHA512SUMS.txt`), so an installed Iskios 0.1.x, which looks for the old name, can update itself into Outlore. Later releases need only the Outlore name: an Iskios that finds a newer release without the old name falls back to the newest one that has it, and once it is Outlore it looks for Outlore names. The updated app keeps the old bundle path (`/Applications/Iskios.app`) until the owner moves it. The Windows and Linux update files name the Outlore installers and need no copy.
- The GitHub repository is referred to as `Dyrits/OUTLORE` (the update check, installer publishing config, README links); the repository was renamed on GitHub on 2026-11-15 at the owner's word ("You do that"), and GitHub redirects the old address. The `outlore-relay` Worker was deployed the same day to the owner's Cloudflare account (`https://outlore-relay.dyrits.workers.dev`); the old `iskios-relay` Worker was left running.
- Kept: the recorded migration id `0041_assistant_renamed_iskios`, and dated documents, which keep the name they were written with.
Reason: The owner wants the product called Outlore, the old name kept only where it is a theme.
References: [backlog](../backlog.md), [glossary](../glossary.md), [brand](../brand/README.md), CHG-0143, CHG-0284.
Validation: The owner's requests in this thread, and the owner's later comment to rename the relay and the storage keys too ("rename the app: Outlore", "keep the old icon for Iskios theme, make One theme the default one", "don't use the icon for now, keep the old one") and answers (full rename; the assistant becomes Chronicler).
